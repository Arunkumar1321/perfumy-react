# Perfumy

A component-based perfume store built with React.js

![React](https://img.shields.io/badge/React.js-blue) ![CSS](https://img.shields.io/badge/CSS3-pink) ![Vercel](https://img.shields.io/badge/Deployed-Vercel-green)

---

## About the Project

Perfumy is a responsive perfume e-commerce UI built using React.js. The project focuses on clean component-based architecture, reusable UI blocks, and a smooth browsing experience — all styled with plain HTML and CSS without any external UI libraries.

---

## Component Structure

| Component | Description |
|---|---|
| `Navbar` | Top navigation with logo and links |
| `Hero` | Banner section with featured perfume |
| `ProductCard` | Reusable card for each perfume item |
| `ProductList` | Grid layout rendering all ProductCards |
| `Footer` | Bottom section with links and info |

---

## Tech Stack

- **React.js** — Component-based UI framework
- **HTML5** — Markup structure
- **CSS3** — Custom styling and layout
- **Vercel** — Deployment and hosting
